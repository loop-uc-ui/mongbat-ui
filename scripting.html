Macro scripts

Write a macro as text, one step per line.

-- Heal, cure and fight
cast "Greater Heal" on self when self.health < 60%
cast "Cure" on target when target.isPoisoned and target.distance <= 10
cast "Energy Bolt" on target when target.isHostile
wait 1.5
say "Next!"

Writing a script

  • Click Script in the Macros window to write the macro as text.
  • Start a line with -- to make it a comment.
  • Case doesn't matter.
  • Put a name of several words in quotes, such as cast "Greater Heal".
  • Press Tab to move through the suggestions, and Enter to take one.
  • A line with a mistake turns red, and the line under the script says what is wrong.
  • Some steps, such as an equipment set, can't be written as a script.
  • Type a cast or skill line in chat with a / in front to run it once, such as /cast "Greater Heal" on self.

Actions

Action Does
cast "Spell" Casts a spell.
skill "Skill" Uses a skill.
ability primary Uses your weapon's primary ability.
ability secondary Uses your weapon's secondary ability.
ability "Ability" Uses a racial ability, such as "Stone Form".
do "Action" Does an action from the Add a step list, such as "Toggle War Mode".
use "Item" Uses an item from your pack. For now only "Bandage".
say "words" Says the words. Also emote, whisper and yell.
wait seconds Waits, such as wait 1.5.
  • Add on self, on target or on cursor to aim cast, skill, do or use.
  • Use use "Bandage" on self to bandage yourself. do "Bandage Self" ends the macro.

Conditions

Add when and a condition to run a step only sometimes.

cast "Greater Heal" on self when self.health < 60%
cast "Cure" on self when self.isPoisoned and not self.isHidden
cast "Heal" on target when (target.isFriend or target.isPartyMember) and target.health < 50%
  • Compare numbers with < <= = != >= >.
  • Use % for a share of the maximum, such as self.health < 60%.
  • Join tests with and, or, not and brackets.
  • A step whose condition fails is skipped.
  • With no target, every target test fails, except not target.exists.

Object handle filters

Add your own filters to the object handles list on the Object Handles page in Settings. A filter is a condition about object.

object.isHostile
object.isPet
object.name("orc or troll")
object.isMobile and object.health < 50% and object.distance < 5
  • object has every test that target has, except exists.
  • A filter can test self too.
  • Use object.name("words") to match the name on the handle, as a search box does.
  • A filter's name and its object.name words can hold only letters, numbers and spaces.
