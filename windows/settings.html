User Settings

Changes how the game and this UI behave.

Opening it

  • Use the Settings action to open it.
  • Choose Settings in your paperdoll's menu to open it.
  • Choose User Settings in the main menu to open it.
  • Right-click the window to close it.

Using it

  • Click a page's name on the left to show that page.
  • Type in the Search box to find options on every page.
  • Click a box to tick or clear it.
  • Click a list and pick an entry.
  • Drag a slider to change its value.
  • Click a button, such as Reset or Apply, to run it.
  • On the Input page, click a command, then press the key you want for it.
  • On the Chat page, pick a channel from Channel to join it.
  • On the Chat page, click Chat Filters or Ignored Players to open those windows.
  • On the Object Handles page, type a name in the Add a filter box to add a filter.
  • Drag a filter's handle to move it, and click its cross to remove it.
  • Pick a language on the Options page to change the UI's language.

Changes

v1.0.0-beta.3

  • Added Disable Overhead Spellcasting Text to the Chat page of User Settings, to hide a spell's words of power over the caster's head.
  • Added Show Spell Names to the Chat page of User Settings, to show a spell's name after its words of power.

v1.0.0-beta.2

  • Changed the buttons in User Settings to act when you let go of the mouse button, as other buttons do.
  • Fixed the press a key prompt in User Settings closing before you press a key.

v1.0.0-beta.1

  • Changed the headings in lists to the usual colour with a line after them.
  • Changed long lists, such as the Step List, to open faster.
  • Changed the Trade, Change Race, Status, Shop, Spellbook and User Settings windows to give their parts more room and line them up.

v1.0.0-alpha.5

  • Added a Chat page in Settings, with the chat channel, combined repeated messages and the chat options.
  • Added a Chat Filters window, to hide a message or replace it with your own words.
  • Added an Ignored Players window, which holds the ignore lists from the old Filters page.
  • Added an Object Handles page in Settings, to write your own object handle filters. It replaces the object handle rows on the Overhead Text page.
  • Changed the Channels window into the Channel list on the Chat page in Settings.
  • Fixed controls in Settings hanging off the window when it is made narrower.

v1.0.0-alpha.4

  • Added and, or, not, brackets and quoted phrases to every find box.
  • Changed the find boxes in Settings, Find a Place and the shop to match the words you type in any order.
  • Changed every find box to stand under its window's title, and every place to type to stand on a dark plate.

v1.0.0-alpha.3

  • The name plate filters add Item Only, Hostile, Friends and My pets. The default UI gets the filter you chose when you go back to it, or every plate for a filter it does not have.
  • Settings offers nine more languages for this UI: French, German, Spanish, Russian, Brazilian Portuguese, Italian, Polish, Czech and Simplified Chinese. On a Japanese, Korean or Traditional Chinese client, this UI's own words are in that language too. Spells, abilities, reagents, context menus and buff names are translated with the rest.
  • Write a log for bug reports, in Settings, writes the log again. Before, the log held nothing.

v1.0.0-alpha.1

  • Your hotbars, key bindings and settings carry over between this UI and the default UI, both ways.
  • Settings come in pages, with a scale for the whole UI.
  • For a bug report, turn on Write a log for bug reports in Settings, under System on the Options page. The game then writes logs/lua.log, with every error, until you turn it off.
