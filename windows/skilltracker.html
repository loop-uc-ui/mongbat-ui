Skill Tracker

Keeps your skills in view while you play.

Opening it

  • Use the Skill tracker action to open it.
  • Right-click the window to close it.

Using it

  • Click the button at the bottom to switch between all skills and your chosen skills.
  • Choose Track this skill in a skill's menu in the Skills window to add it.
  • Choose Stop tracking in the same menu to remove it.
  • Hover over a skill to see its value and cap.

Changes

v1.0.0-alpha.1

  • The skill tracker keeps your skills in view, either every skill above zero or only the ones you choose to watch.
