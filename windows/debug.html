Debug Log

Shows the client's log inside the game.

Opening it

  • Type /debug in chat in a debug build to open it.
  • Right-click the panel to close it.

Using it

  • Click Inspect and point at a window to outline it and log what it is.
  • Click Stop inspecting to stop.
  • Click Reload UI to load the UI again.
