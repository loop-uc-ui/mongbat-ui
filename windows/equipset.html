Equip Items

Edits the set of items a hotbar slot puts on.

Opening it

  • Shift+right-click a hotbar slot with an equipment set and choose Edit Item.
  • Right-click the window to close it.

Using it

  • Drag an item from your paperdoll or backpack onto the window to add it.
  • Click the empty row while carrying an item to add it.
  • Click Add Equipped to add everything you are wearing.
  • Shift+right-click a piece and choose Take out of the set to remove it.
