Name Plates

Shows the names of the items and creatures near you.

Opening it

  • Hold Ctrl and Shift to show the plates.
  • Let go of Ctrl and Shift to hide them.

Using it

  • Turn the mouse wheel or click a filter to choose which plates show.
  • Click a creature's plate to target the creature.
  • Drag a creature's plate to pull off its health bar.
  • Drag an item's plate to pick the item up.
  • Double-click a plate to use the object.
  • Hover over a plate to see the object's properties.
  • Right-click a plate to close it.

Changes

v1.0.0-beta.2

  • Changed an item's name plate to go away as soon as you pick the item up.
  • Fixed the Corpses filter showing no name plates.

v1.0.0-alpha.5

  • Added an Object Handles page in Settings, to write your own object handle filters. It replaces the object handle rows on the Overhead Text page.

v1.0.0-alpha.4

  • Changed a creature's or a player's name in a tooltip to show in their notoriety colour.
  • Changed the name plates' filter list to look like a menu, under the title Object Handles.

v1.0.0-alpha.3

  • While you hold Ctrl and Shift for the name plates, a list of filters shows with them. Turn the wheel anywhere, or click a filter, and the plates change at once. Drag the list to move it, and it opens where you left it. Your choice is saved when you let go.
  • The name plate filters add Item Only, Hostile, Friends and My pets. The default UI gets the filter you chose when you go back to it, or every plate for a filter it does not have.
  • A name plate's hover no longer shows only the name that is already on the plate.
