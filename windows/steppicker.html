Windows

Step List

Lists every action a macro step can be.

Opening it

  • Click Add a step in the Macros window to open it.
  • Click Change in the Step Editor to open it.
  • Right-click the window to close it.

Using it

  • Type in the Search box to filter the actions.
  • Click an action to add it as a step.
  • Drag an item from a bag onto the macro to add it.
