Key Prompt

Asks you to press the key you want for an action.

Opening it

  • Choose Assign Hotkey from a hotbar slot's menu to open it.
  • Click No Key Binding in the Macros window to open it.
  • Click a command in the key settings of the Settings window to open it.
  • It closes when you press a key.

Using it

  • Press the key you want, with Control or Alt held if you like.
  • Press Escape to clear the action's key.
  • If the key is already in use, answer yes to move it.

Changes
