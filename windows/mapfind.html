Find a Place

Finds a place by name and moves the map to it.

Opening it

  • Choose Find a place in the map's menu.
  • Use the Find a place action to open it.
  • Right-click the window to close it.

Using it

  • Type part of a name to list the places that match.
  • Click a row to move the map to that place.
  • Press Enter to move the map to the first row.
  • Hover over a row to read the place's world and position.
