Chat Line

The box you type in to speak.

Opening it

  • The line shows whenever the chat window shows.
  • Press the chat key to start typing.
  • Press Escape twice to leave the line.

Using it

  • Type and press Enter to send the line.
  • Press Shift+Up and Shift+Down to bring back lines you sent.
  • Start a line with a channel's short word, such as /p for Party, to switch channels.
  • Type a window's command, such as /map, and press Enter to open or close it.
  • Type /cast or /skill with a name to use a spell or a skill.
  • Type /logout or /exit to log out or leave the game.

Changes

v1.0.0-alpha.5

  • Added /cast and /skill in chat.
  • Changed the chat to drop its menu and the Global Chat friends window. Type a channel's shortcut to switch channels.
  • Changed the lines you typed to be kept in the client's memory, not in your character file.
  • Fixed /w answering that it is an unknown command.

v1.0.0-alpha.2

  • Type a command alone on the chat line to open or close a window, such as /status, /paperdoll, /backpack, /skills, /map or /settings. A command is not said aloud.
  • Type /logout or /exit on the chat line to log out or leave the game at once, without being asked.

v1.0.0-alpha.1

  • The chat has a menu for channels, Global Chat friends and ignore lists.
