Map Legend

Picks which kinds of marker the map draws.

Opening it

  • Choose Legend in the map's menu.
  • Use the Legend action to open it.
  • Right-click the window to close it.

Using it

  • Click a row to turn that kind of marker off or on.

Changes

v1.0.0-alpha.1

  • The map lists only your own waypoints, and has a find box and a legend.
