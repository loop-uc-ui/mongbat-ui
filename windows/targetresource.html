Harvest With

Sets what a hotbar slot's tool harvests.

Opening it

  • Shift+right-click a harvest slot on a hotbar and choose Edit Item.
  • Right-click the window to close it.

Using it

  • Drop a tool on the first row to set the tool.
  • Click a resource to aim the slot at it.
