First Run Questions

Asks how to set up a character that is new to this client.

Opening it

  • It opens when you log in with a character that has never answered.
  • Right-click the window to put it away without answering.

Using it

  • Click a choice to pick it.
  • Hover over a choice to read what it will do.
  • Click Okay to send your answers.
