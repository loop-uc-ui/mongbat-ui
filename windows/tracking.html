Tracking Arrow

The tracking arrow points from the edge of the game view toward a target that the server is pointing you to, such as a creature. You see it when you use the Tracking skill, and when a quest points you to a target.

The arrow turns as you move, so that it always points the way to the target. It is only a picture over the world, and it takes no clicks.

Opening it

  • The arrow appears when the server starts pointing you to a target, as it does when you use the Tracking skill.
  • It goes away when the server stops pointing.

Using it

  • The arrow takes no clicks, so a click goes through it to the world.
  • Walk toward the way it points to reach the target.
