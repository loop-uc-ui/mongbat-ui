Names and Speech Over Heads

Shows names and speech over the heads of people and creatures.

Opening it

  • A name appears when someone comes into view.
  • Speech appears when someone talks, and fades after a while.

Using it

  • Set Show Names on the Overhead Text page of Settings to choose which names show.
  • Turn Overhead Chat on or off on the same page.
  • Set Overhead Chat Fade Delay to choose how long speech stays.
  • Press the client's key that flashes all names to see every name for a few seconds.

Changes

v1.0.0-beta.3

  • Added Disable Overhead Spellcasting Text to the Chat page of User Settings, to hide a spell's words of power over the caster's head.
  • Added Show Spell Names to the Chat page of User Settings, to show a spell's name after its words of power.
  • Fixed a curly quote in a chat line drawing as a stray mark, and an accented letter being dropped.
