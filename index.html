mongbat-ui

A replacement interface for the Ultima Online Enhanced Client. It changes how the game's windows look and work. It does not change the game itself, and you can switch back to the default interface at any time.

Install

You need the Ultima Online Enhanced Client. The Classic Client cannot load a custom interface.

  1. On the releases page, open the newest release and download its zip file. The file is named after the release tag, for example mongbat-ui-v1.0.0-beta.1.zip.
  2. Open the folder where the game is installed. On Windows it is usually C:\Program Files (x86)\Electronic Arts\Ultima Online Enhanced.
  3. In that folder, open UserInterface. If there is no folder with that name, create it.
  4. Unzip the download into UserInterface. You now have a folder named UserInterface\mongbat-ui. If the game is installed under Program Files, Windows may ask for administrator permission to copy the files.
  5. Start the game. On the login screen, click Custom UI.
  6. Under Use Custom UI, choose mongbat-ui, then click Okay.

Update

Delete the folder UserInterface\mongbat-ui, then follow the install steps with the newest release. Deleting the old folder first removes files that the new release no longer uses.

Remove

On the login screen, click Custom UI and choose Default. Then delete the folder UserInterface\mongbat-ui.

Problems

Report a problem on the issues page. Say:

  • which release you installed,
  • what you did, what you expected and what happened,
  • a screenshot, if the problem can be seen.

A log helps. In the game, open Settings, and on the Options page, under System, turn on Write a log for bug reports. Make the problem happen again. The game writes logs/lua.log in its install folder. Attach that file to the issue as a file, by dragging it in. Do not paste it, because it is UTF-16 text. Copy the file before you start the game again, because the game rewrites it at every start. Then turn the setting off, because the file grows while it is on.
